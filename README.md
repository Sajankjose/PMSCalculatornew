# PMS Fees Calculator — UI/UX Redesign

This is a drop-in replacement for the current GitHub Pages calculator.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Deploy
Replace the corresponding files in the root of the `Sajankjose/pmscalculator` repository and commit to the branch used by GitHub Pages (currently `main`).

## What changed
- UI redesigned to match the supplied reference.
- Fee-plan segmented control.
- Large investment input.
- Sliders for other expenses and investment period.
- Editable yearly return controls inside the results table.
- Instant recalculation; no Calculate button required.
- Responsive layout for desktop, tablet and mobile.
- Existing PMS calculation approach and fee-plan logic retained.
